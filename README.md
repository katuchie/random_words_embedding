# random_words_embedding


Анализ эмбеддингов слов — превращаем слова в векторы и ищем похожие по смыслу.

##  Что делает проект

- Превращает слова в **числовые векторы** (эмбеддинги)
- Находит **слова, похожие по смыслу** (кот → кошка)
- Рисует **красивые графики** связей между словами
- Показывает, какие слова **уникальные**, а какие — обычные
